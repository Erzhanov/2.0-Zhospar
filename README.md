# ZHOSPAR 2.0 — Flutter App

Бұл жоба — **ZHOSPAR WWEB** веб-нұсқасының толықтай Flutter-ге көшірілген мобильді/кросс-платформалық қосымшасы. Дәл сол дизайн жүйесі (iOS стилі, минимализм, Apple Human Interface Guidelines), дәл сол мүмкіндіктер мен бірдей Supabase деректер қорымен жұмыс істейді.

---

## 📱 Мүмкіндіктері (Features)

1. **Авторизация және Қауіпсіздік (Supabase Auth):**
   - Email және құпиясөз арқылы кіру және тіркелу.
   - Сессияны құрылғыда сақтау (`autoRefreshToken: true`).
   - Пайдаланушы рөлдерін тексеру (Әкімші / Admin ролі).

2. **Басты бет (Dashboard):**
   - Ағымдағы апта прогресі (жалпы, орындалғаны, пайыздық көрсеткіш).
   - Стрик (🔥 үздіксіз күн сериясы).
   - Апталық дәйексөз (Weekly quote) — бірден өңдеп сақтау.
   - Дүйсенбіден Жексенбіге дейінгі күн таңдау тақтасы (күндер нөмірі, бүгінгі күн индикаторы).
   - Таңдалған күннің тапсырмалары (орындалуын белгілеу, уақыт, категория, приоритет).
   - Күндік рефлексия жазу блогы.
   - Жылдам әрекеттер (Апта жоспары, Таймер, AI Көмекші, Аналитика, Қорытынды, Мұрағат).

3. **Апталық Жоспар (Weekly Plan):**
   - Апталарды алға/артқа ауыстыру (`<` және `>`), ағымдағы аптаға қайту.
   - Әр күнге тапсырма қосу, өңдеу және өшіру.

4. **Аналитика (Analytics):**
   - Орындалу пайызы, орындалған және қалған тапсырмалар саны.
   - Күндік стрик есептегіші.
   - Апталық интерактивті бағандық диаграмма (`fl_chart` BarChart).

5. **AI Көмекші (AI Assistant):**
   - Апталық контекстке бейімделген AI көмекші чаты.
   - Дайын ұсыныстар (Оқу жоспары, күн кестесі, мотивация).
   - **Жоспарды күнтізбеге қосу:** AI жасаған кестені талдап (`extract-plan`), бір батырмамен тексеріп апталық кестеге қосу (`PlanReviewDialog`).

6. **Фокус Таймері (Pomodoro Focus Timer):**
   - 3 режим: Жұмыс / Фокус, Қысқа үзіліс, Ұзақ үзіліс.
   - Пресеттер: Помодоро (25 мин), Терең жұмыс (50 мин), Оқу (45 мин), Жылдам (15 мин).
   - Айналмалы кері санақ таймері.
   - Дыбыстық және вибро-сигнал.
   - Фондық атмосфералық музыка таңдау (Lofi Girl, Jazz Hop, Deep Focus, Calm Piano, Night Walk, Қазақ Lo-Fi).

7. **Апталық Қорытынды (Weekly Review):**
   - 4 негізгі рефлексия сұрағы:
     1. Не үйрендім?
     2. Не жақсы өтті?
     3. Не қиын болды?
     4. Нені өзгерту керек?
   - Келесі аптаға 3 басты мақсат қою.
   - Supabase-ке сақтау.

8. **Мұрағат (Archive):**
   - Өткен барлық апталардың тарихы мен жетістіктері.
   - Әр аптаны ашып-жабу (аккордеон).
   - **Орындалмаған тапсырмаларды келесі аптаға көшіру**.
   - Іздеу жүйесі.

9. **Баптаулар (Settings):**
   - Жарық (Light) және Қараңғы (Dark - OLED Pure Black) тақырыптарды таңдау.
   - 3 тілді қолдау: 🇰🇿 Қазақша, 🇷🇺 Русский, 🇬🇧 English (бірден ауысады).
   - Қосымша нұсқаулығын (Onboarding) қайта бастау.
   - Тіркелгіден шығу.

10. **Әкімші тақтасы (Admin):**
    - Әкімші рөлі бар қолданушыларға жүйелік параметрлерді қарау мүмкіндігі.

## 🛠️ Қолданылған технологиялар

- **Flutter 3.47+ / Dart 3.13+**
- **Supabase Flutter (`supabase_flutter`)** — Auth, Database, Functions
- **Provider (`provider`)** — Мемлекеттік басқару (State management)
- **Google Fonts (`google_fonts`)** — Inter қаріптер жиынтығы
- **FL Chart (`fl_chart`)** — Аналитикалық диаграммалар
- **Audioplayers (`audioplayers`)** — Дыбыстық эффектілер мен фондық музыка
- **Shared Preferences (`shared_preferences`)** — Жергілікті баптауларды сақтау

## 🚀 Қосымшаны іске қосу (How to run)

1. Жоба папкасына өтіңіз:
   ```bash
   cd zhospar_app
   ```

2. Тәуелділіктерді жаңарту:
   ```bash
   flutter pub get
   ```

3. Қосымшаны эмуляторда, құрылғыда немесе Windows/Chrome-да іске қосу:
   ```bash
   flutter run
   ```

4. Android APK жинау:
   ```bash
   flutter build apk --release
   ```

5. Windows нұсқасын жинау:
   ```bash
   flutter build windows --release
   ```
